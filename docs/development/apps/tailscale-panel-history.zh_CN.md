# 网络面板 —— 交付历史

网络面板应用(np- 前缀固件版本)的逐版本交付记录。每条标题按 Conventional
Commits 主题风格书写,提交该版本时可直接作为提交说明的种子;正文保留当轮的
决策、取舍、门禁结果与精确镜像身份。按时间顺序排列,新版本追加在末尾。条目
描述的是**该版本当时**的固件,不回溯改写;现行规格说明见
[tailscale-panel.zh_CN.md](tailscale-panel.zh_CN.md)。

设备状态标记,按当时记录:**Flashed** = 用户已从硬件回报结果;**等待刷机** =
门禁已验证但未从硬件回报。`np-0.1.8` 之前的条目记的是改名前的固定镜像名;
那些文件已不在 `build/`,只能按内容哈希在 `build/firmware/<sha256>/` 里找到。

## np-0.1.12 — feat(diag): 分层的 Tailscale 失败报告;移除自动压暗

## np-0.1.14 — fix(mem): HTTP 响应缓冲改为握手完成后分配
